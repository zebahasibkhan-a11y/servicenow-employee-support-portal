# servicenow-employee-support-portal
ServiceNow IT Service Management & Employee Support Portal

Project Overview

This project focuses on developing an IT Service Management (ITSM) and Employee Support Portal using the ServiceNow platform.

The portal aims to streamline IT support operations, manage employee requests, and automate service workflows.

Project Objectives

* Manage IT incidents efficiently.
* Automate employee service requests.
* Improve IT support processes.
* Track and resolve technical issues.

Modules

1. Incident Management
2. Problem Management
3. Change Management
4. Service Catalog
5. Service Level Agreements (SLA)
6. Employee Support Portal

Technologies

* ServiceNow
* JavaScript
* GlideRecord
* Business Rules
* Client Scripts
* Flow Designer
